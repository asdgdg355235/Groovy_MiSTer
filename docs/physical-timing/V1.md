# V1: Q25 VGA/root next-line arithmetic experiment

* Exact control source: `3b8d1edb63f2d2fed05d23323c3ba1ae93eeed1a`
* Compiler: Quartus Prime Lite 25.1std.0 Build 1129
* FPGA: `5CSEBA6U23I7`
* Source delta: `Groovy.sv` only.
* No pin, clock, PLL, seed, constraints, RAM, or physical assignment changes.

The slow -40C R0 path launches at generated `vga|Add1~105_OTERM3868`
and captures at generated root `Add17~5_OTERM5723` (WNS -0.097 ns).
The available mapping does not prove either generated register corresponds
specifically to the next-line expression. The experiment shortens that
independently identified root arithmetic by using a shared 17-bit increment:
`vga_vcount + (PoC_interlaced ? 2 : 1)`. The 17th bit preserves
rollover 65535 + 2. Its use in comparisons and 24-bit products follows
the original expression's context widths. No register is inserted.

The exact pre-optimization Q25 hardware hashes remain in
`tests/physical/hardware_q25.json`. The sole source replacement, its
SHA-256, and control commit are recorded in
`tests/physical/q25_targeted_experiment.json`.
The runner also freezes generated build-id bytes and records raw QSF calls.

Non-Quartus verification includes the existing VGA/interlace, geometry,
frame-skip/RTL lint, CRT, RAM and LZ4 suites plus the V1 next-line width
equivalence regression. The formal arithmetic identity does not demonstrate
a Quartus timing improvement or full root-controller cycle equivalence.

Use an independent clean worktree and a new directory:

```bash
git worktree add --detach ../Groovy-Q25-V1 experimental/q25-vga-arithmetic
cd ../Groovy-Q25-V1
export QUARTUS_25_BIN=/home/taichi/altera_lite/25.1std/quartus/bin
CRT_READ_BUILD_DIR="$PWD/../Groovy-Q25-V1-build" \
  bash tests/run_physical_timing_quartus.sh V1 --profile q25 --quartus-bin "$QUARTUS_25_BIN"
```

Do not run this script inside CI. It invokes the user's local Quartus tools.
Preserve `../Groovy-Q25-V1-build-reports.tar.gz` including failed builds.
Compare against the sealed `3b8d1edb63f2d2fed05d23323c3ba1ae93eeed1a` Q25 R0 archive, not Q17.
Acceptance requires positive or zero setup WNS at all 8 corners plus
unregressed hold/recovery/removal/pulse and validated physical diagnostics.
