# V1 blanking-sum source experiment

Reference basis: 3b8d1ed rtl/vga.v V_total at line 109; native Add1/Add0 source
locations & cold critical path in the measured Q25 R0. Root Add17 is the frame-skip
operand at Groovy.sv:1078, not a field-height expression.

This branch preserves the R0 checkout RTL & immutable Q25 hardware manifest.
V1 is a complete reviewed patch, applied only to a fresh V1 source snapshot.
The original hash, result hash & patch hash are in tests/physical/variants/V1.json.
`hardware_hashes(..., experiment='R0')` still rejects modified VGA RTL.

V1 computes a 10-bit unsigned VBP+VFP+VS sum before the V-dependent 16-bit add,
then retains the field decrement. The terminal predicate, counter updates & root
arithmetic are unchanged. No pipeline cycle, timing constraint or assignment is
added. R0-DIAG repairs are included as shared reporting infrastructure.

Independent checks:

```bash
python3 tests/prove_v1_blanking.py
python3 tests/run_v1_vga_compare.py
python3 tests/run_timing_candidate_tests.py
```

The VGA test applies the patch to frozen 3b8d1ed RTL, checks Verilog-2001 syntax,
then compares every output & relevant counter on every simulated clock. It uses
explicit FIFO/overlay models. A focused wrapper extracts the actual root frame-skip
decisions & S_Blit_Auto_Skip arithmetic; it does not simulate the entire DDR FSM.
Reset, CE stalls, interlaced fields, runtime modes & overflow boundaries are covered.
Paired counter-state injections exercise boundary states without waiting 65535 lines.
The SMT identity is finite-width expression evidence, not sequential or timing proof.
